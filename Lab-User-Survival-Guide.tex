\section{Before You Start}
\begin{itemize}
  \item Wear required personal protective equipment (PPE).
  \item Read the experiment protocol before entering the lab.
  \item Verify emergency exits and spill-kit locations.
\end{itemize}

\section{Daily Lab Rules}
\begin{itemize}
  \item Label all samples with date, initials, and contents.
  \item Keep benches clean and return shared equipment after use.
  \item Record all observations in your lab notebook the same day.
\end{itemize}

\section{If Something Goes Wrong}
\begin{itemize}
  \item Stop work immediately if you notice unsafe conditions.
  \item Inform the supervisor and follow incident reporting procedures.
  \item Do not restart work until the issue is resolved.
\end{itemize}
